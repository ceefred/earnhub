# EarnHub website prototype

This is a static pre-launch prototype. It does not include real user accounts, database storage, provider integrations, task tracking, or payment processing.

## Files
- `index.html` — main demo
- `privacy.html` — pre-launch privacy policy draft
- `terms.html` — pre-launch terms draft
- `contact.html` — pre-launch contact placeholder

## Publish free with GitHub Pages
1. Create a **public** GitHub repository named `earnhub` (or another name).
2. Upload the contents of this folder to the root of the repository. Make sure `index.html` is at the root, not inside another nested folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for the published site link to appear in Settings → Pages. Project sites normally use `https://YOUR-USERNAME.github.io/REPOSITORY/`.

Important: GitHub Pages only hosts static files. Do not put passwords, API keys, secret tokens, or personal data in this public repository. This prototype is not ready to accept users or money. Before a real launch, build a secure backend for authentication, balances, server-side provider callbacks, fraud controls, and payouts. Replace the contact placeholder and review the policy/terms drafts. Apply to providers honestly and only show integrations after approval.
